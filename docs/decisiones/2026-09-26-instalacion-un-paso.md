# Instalación de un paso: agente, server, buffer offline y actualización (2026-09-26)

Meta del usuario: el server solo se instala y el agente solo se instala, se ejecuta y se enrola. Implementado por agentes especializados y verificado por el orquestador con `check-go.sh all` (server y agente, con `-race` local del agente) y `check-web.sh`. **Nada de esto se probó todavía en un SO real**: el usuario valida el instalador en Linux y Windows; macOS queda sin validar (no tiene equipo).

## Agente
- **Buffer offline persistente** (`agent/internal/sender/queue.go`): `buffer.log` en el directorio de estado (mismos permisos que el estado), journal append-only con compactación atómica. Topes: 2000 reportes o 20 MB (descarta el más viejo). Reenvío del más viejo primero, respetando el rate limit del server; descarta reportes de más de 6 días (`MaxAge`; el server acepta hasta 7) y los rechazados con 400; 5xx/red se reintentan. Archivo corrupto → se descarta con un log sin datos; una cola cortada por `kill -9` conserva lo válido. Solo reportes de métricas. Limitación: los extras (discos/`host_info`) de un reporte descartado por tope no se persisten; tras un reinicio con buffer viejo reenvía a 1 reporte cada 2,5 s.
- **Config local desde `install`** (`agent/internal/config/settings.go`): `argos-agent install --inventory <ports,services,processes,updates|all> --probe-allow <cidr,...> --insecure` (además de `--ca-file` y `--privileged`) se guardan en `settings.json` del estado; precedencia **entorno > archivo > defecto** con los mismos parsers de las variables. Funciona en systemd, SCM y launchd sin variables de entorno del servicio. `status` muestra la config efectiva sin secretos. Seguridad: la config es solo local, nunca la decide el server; `--probe-allow` rechaza `0.0.0.0/0`, `::/0` y redes mayores que /24. Con el servicio ya instalado, `install` + flags solo actualiza `settings.json`; cambiar `--privileged`/`--ca-file` exige `uninstall --keep-state` + `install`. Más de 256 IPs de sondeo exige `ARGOS_PROBE_MAX_TARGETS`.
- **`argos-agent update`** (`agent/internal/updater`): pide `/dl/latest/manifest.json`, verifica el sha256, reemplaza el binario (Linux/macOS por `rename`; Windows: exe actual → `.old`), conserva estado y config y reinicia el servicio; si el nuevo no arranca restaura `.old` y sale con error. Rechaza builds `dev` y no hace downgrade. **Deuda aceptada por el usuario:** sin firmas independientes del server (solo el sha256 del manifiesto).
- **Instaladores** (`server/internal/httpapi/installers/`): `install.sh` acepta `--inventory --probe-allow --privileged --insecure --update`; `install.ps1` `-Inventory -ProbeAllow -Privileged -Insecure -Update`, con lista blanca de caracteres (probado con valores maliciosos). Actualizar: `curl … /install.sh | sh -s -- --update`.
- **Web (modal "Agregar host")**: bloque "Opciones del agente" (inventario y parches marcados por defecto; sondeo con CIDR validado; privilegiado; "servidor http" solo si el origen es `http://`) que añade los flags al comando antes de copiarlo (`applyAgentOptions` en `utils/enroll.ts`). Deuda: el origen para `--insecure` es `window.location.origin`.

## Server
- **`deploy/install-server.sh` de un paso**: `--install-postgres` (PGDG, solo Debian/Ubuntu), `--with-caddy` con `--domain` (Let's Encrypt) o `--tls-internal` (CA interna), `--admin-user`/`--no-admin`, `--dry-run` (imprime todo sin ejecutar ni exigir root). Ejemplo: `sudo bash deploy/install-server.sh --public-url https://argos.lan --install-postgres --create-local-db --with-caddy --tls-internal --admin-user admin`. Idempotente; el primer admin usa una clave aleatoria impresa una sola vez y **`create-admin --must-change`** (nuevo) obliga a cambiarla en el primer login. Wrapper `argos-admin` ahora es un archivo del paquete (`deploy/argos-admin`). Riesgos anotados: la URL de la BD viaja un instante por argv a `psql` en la comprobación de admin; sin verificación de huella de las claves GPG (solo `signed-by`); si ya existe el usuario elegido sin ser admin, `create-admin` falla tras dejar todo instalado. **No probado en Linux real** (apt, PGDG, Caddy, ufw, systemd, `runuser`).
