# Agente: metricas, enroll, transporte, estado y resiliencia (2026-09-23)
Contrato HTTP del server intacto. Dependencia aprobada: SOLO `github.com/shirou/gopsutil/v4` (v4.26.8); transitivas (`go-ole`, `wmi`, `purego`, `go-sysconf`, `numcpus`, `perfstat`, `plan9stats`, `x/sys`); `x/sys` subido a v0.48.0 (v0.41.0 tenia GO-2026-5024, Windows, no alcanzable). Colectores nuevos y servicio del SO: `agente-colectores-y-servicio.md`.

- **Layout**: `internal/{config,state,transport,enroll,sender,agent,collector,service,quiet}` + `cmd/agent/{main,app}.go`. `Collector` (interfaz de 1 metodo) vive en `agent` (donde se consume); `collector.System` es la implementacion gopsutil. `main` solo cablea y traduce el error a codigo de salida; los subcomandos viven en `app` (testeable con env, stdout, colector y logger inyectados).
- **Metricas base**: el server valida `metrics.net.{rx_bytes,tx_bytes}` (anidado, int64). Contadores acumulados de todas las interfaces sin flag `loopback` (cuentan virtuales tipo docker/veth: pedido explicito). CPU: la primera lectura mide una ventana de 1 s (primer envio ~1 s tras arrancar), luego delta desde el ciclo anterior. Si una medicion obligatoria falla se omite el ciclo (nunca un cero falso).
- **Enroll**: `argos-agent enroll --server URL --token T [--force]` o `ARGOS_SERVER_URL`/`ARGOS_ENROLL_TOKEN` (el flag pisa al env; el env es preferible: la linea de comandos es visible). Manda `{enroll_token, os, arch}` sin Authorization. Solo imprime `host_id` y la ruta del archivo; errores (401 = "enroll token invalido, usado o expirado", 429, otros) nunca incluyen el token. Enroll sobre estado existente exige `--force` (el host anterior queda huerfano: revocarlo). El directorio de estado se prepara ANTES de llamar al server pa no quemar el token de un solo uso; si el guardado falla despues, el error dice el `host_id` a revocar.
- **Estado**: `<ARGOS_STATE_DIR>/agent.json` (`{host_id, agent_token, server_url}`), default `os.UserConfigDir()/argos-agent` (con servicio: ver su archivo); escritura atomica (temp en el mismo dir + fsync + rename). Unix: dir 0700, archivo 0600. Windows: ACL con `SetNamedSecurityInfo` (perm_windows.go; reemplaza a `icacls`), uso normal = solo el SID del usuario actual; modo servicio: ver `agente-colectores-y-servicio.md`. Efecto: apuntar `ARGOS_STATE_DIR` a un directorio compartido le quita la herencia.
- **Precedencia**: `ARGOS_AGENT_TOKEN` (override, solo token) > archivo. URL: `ARGOS_SERVER_URL` > la guardada (con override de token por env, la URL debe venir por env). Sin token ni archivo: error que explica como enrolar. `ARGOS_SERVER_URL` es URL base (sin path).
- **Transporte**: `http://` solo hacia loopback (`localhost`, 127.0.0.0/8, ::1), salvo `ARGOS_ALLOW_INSECURE=1` (`1|true|0|false`; otro valor falla) con WARN fuerte; aplica a `enroll` y `run`. `ARGOS_CA_FILE`: `x509.CertPool` propio con SOLO esa CA; TLS >= 1.2; jamas `InsecureSkipVerify`. Un `http.Client` (timeout 10 s) que NO sigue redirecciones (3xx = error). Token solo en `Authorization: Bearer`, nunca en body ni URL; URL con credenciales embebidas se rechazan.
- **Resiliencia**: 3 intentos por flush, backoff 1s->30s con jitter pa 5xx/red/408; `Retry-After` (segundos o fecha HTTP, tope 5 min) manda sobre el backoff en 429/5xx. 4xx definitivo (no 401) descarta el reporte y loguea. Buffer en memoria de 120 reportes (descarta el mas viejo). Vaciado tras caida: envios separados 2,5 s (`DrainPace`; limite del server 1 req/2 s, rafaga 5) y cada `Send` procesa como mucho `Interval/DrainPace` reportes (12 con 30 s); el resto sale en ciclos siguientes. Aviso al arrancar si usa `http` hacia host no-loopback.
- **401 = token rechazado** (no se reintenta ni se descarta el buffer): `run` en primer plano loguea "token rechazado: re-enrola el agente" y **sale con codigo 2** (0 ok, 1 error); re-enrolar con `enroll --force`. En modo servicio NO sale: ver `agente-colectores-y-servicio.md`.
- `ARGOS_INTERVAL` default 30 s, minimo 5 s.
- Pendientes abiertos: persistencia del buffer en disco (libreria no aprobada, p. ej. SQLite), rotacion del agent token (ver indice). Disco y load average ya se recolectan (ver archivo hermano).
